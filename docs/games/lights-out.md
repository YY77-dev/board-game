# Lights Out 仕様メモ

> たたき台です。「未定」の項目は、作りながら決めて書き換えます。

## ルール

- 盤面は N×N のマスでできていて、各マスは点灯か消灯のどちらか。
- マスをクリックすると、そのマスと上下左右に隣り合うマスの状態が反転する。盤面の端では、はみ出した分は無視する。
- すべてのマスを消灯させたらクリア。

## 盤面

| 項目 | 内容 |
|---|---|
| サイズ | 5×5 で固定（v1） |
| 初期盤面 | すべて消灯の盤面から、ランダムなマスを K 回クリックして作る |
| K の値 | 未定。10 前後から試す |

### 初期盤面の注意点

- 点灯するマスをランダムに選ぶと、解けない盤面ができることがある（5×5 では、ランダムな盤面の 4 分の 3 が解けない）。そのため、上の「消灯盤面から逆にクリックする」方法を使う。
- 同じマスを 2 回クリックすると元に戻る。そのため K 回クリックしても、作られた盤面が K 手で解けるとは限らない。
- 生成した盤面がたまたま全消灯になった場合は作り直す。

## 画面

URL は `/lights-out`。

- 盤面（点灯と消灯が色ではっきり分かるようにする）
- 手数の表示
- 「新しい問題」ボタン（盤面を作り直し、手数を 0 に戻す）
- クリアしたら、手数と一緒にメッセージを出す。クリア後は盤面をクリックできないようにする。
- トップページへ戻るリンク

## 実装の方針

### ファイル構成

```
frontend/src/
├── app/lights-out/page.tsx         # 画面
└── games/lights-out/
    ├── logic.ts                     # ゲームのロジック（React に依存しない）
    └── logic.test.ts                # ロジックのテスト
```

### ロジック（`logic.ts`）

盤面は `boolean[][]` で表す。`true` が点灯。関数は渡された盤面を書き換えず、新しい盤面を返す。

| 関数 | 役割 |
|---|---|
| `createSolvedBoard(size)` | すべて消灯の盤面を返す |
| `toggle(board, row, col)` | クリックした後の盤面を返す |
| `isSolved(board)` | すべて消灯なら `true` |
| `generatePuzzle(size, clicks, random?)` | 初期盤面を返す。テストで結果を固定できるよう、乱数関数を引数で差し替えられるようにする |

### テストで確かめること

- `toggle` で、中央・角・辺のマスを押したときに反転するマスが正しいこと
- 同じマスを 2 回 `toggle` すると元の盤面に戻ること
- `toggle` が元の盤面を書き換えないこと
- `generatePuzzle` の結果が全消灯にならないこと

### UI

- Mantine と Tailwind を使う（既存の構成に合わせる）。
- 状態（盤面、手数、クリア済みかどうか）は、ひとまず page 内の `useState` で持つ。
- 各マスは `button` にして、キーボードでも操作できるようにする。
